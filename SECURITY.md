# Security

The runtime loads model files and runs them, so a malformed file must never cause an out-of-bounds read or write.
If you find a way to make it do so, or any other security problem, please report it privately to
[support@seal.computer](mailto:support@seal.computer) with "Security" in the subject, and do not open a public issue.

Include the build you used, the file or input that triggers it, and what happens. We will acknowledge your report and
tell you what we plan to do about it.
